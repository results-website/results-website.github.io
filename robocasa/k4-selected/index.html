Four selected K=4 examples

Raw learned features, original four selected points and forecasts, their upsampling to 256 policy points, same-frame uniform-256 predictions, and actual rollout endings. All images here use the chosen external camera.

256 policy points and 256×256 image size are separate. Point and feature images enlarge the original 128×128 image. Feature maps are recomputed by replaying the original recorded actions with the evaluation renderer settings; the original saved points and forecasts are preserved. Feature colors use one shared PCA across the four examples.

Failure panels show genuine failed complete rollouts. Method names and query counts are explicit. Uniform-256's own ending is included separately, including successes.
